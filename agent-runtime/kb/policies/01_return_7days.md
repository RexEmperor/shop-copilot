# 七天无理由退货规则

## 适用时效与基本条件
自买家实际签收商品次日零时起算满 7 个自然日（即 168 小时）内，在不影响商品二次销售的前提下，买家可发起“七天无理由退货”申请。
商品完好标准包括：
- 商品本体无划痕、无污渍、无磕碰、无明显使用痕迹；
- 原厂包装、吊牌、说明书、充电线及赠品齐全且无破损；
- 数码类商品未激活绑定个人账号、无拆机维修痕迹。

## 不适用七天无理由退货的商品
以下商品因性质特殊，除存在质量问题外，不支持七天无理由退货：
1. 食品类商品（如每日坚果礼盒、挂耳咖啡）一经拆封影响食品安全与二次销售的；
2. 贴身穿着服饰已剪除吊牌、水洗或沾染明显异味污渍的；
3. 消费者定制类商品、鲜活易腐商品以及页面已明确标注“不支持七天无理由退货”的特殊商品；
4. 随订单附带的赠品未一并退回且影响整单核销的。

## 办理流程与时效
买家在系统提交退货退款申请后，商家将在 48 小时内审核并给出退货地址。审核通过后，买家需在 7 日内寄回商品并填写物流单号；商家签收并质检无误后，将在 48 小时内完成原路退款。
