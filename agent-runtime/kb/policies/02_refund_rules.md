# 仅退款与退货退款适用规则

## 按订单状态的售后类型限制
为保障交易资金与履约一致性，系统严格按订单当前状态校验可申请的售后类型：
- **待支付（未付款）订单**：尚未产生实际扣款，不支持发起仅退款或退货退款；如不再购买，可直接取消订单或等待超时自动关闭。
- **已取消订单**：订单已关闭，不支持发起售后。
- **已支付（暂未发货）订单**：商品尚未发出，**仅支持申请“仅退款”**，不支持申请“退货退款”。
- **已发货或已完成（已签收）订单**：支持申请“仅退款”或“退货退款”。若买家已收到商品且无严重破损，通常需选择“退货退款”并寄回商品。

## 退款金额与到账时效
- 退款金额严格以订单实际支付总金额为准，由系统按订单金额自动计算，不支持手动篡改或超额退款。
- 同一笔订单同一时间仅允许存在 1 条进行中（待审核或退款中）的售后工单；若前序工单被驳回，买家可补充凭证重新发起。
- 审核通过进入退款中后，款项将原路退回原支付账户：微信/支付宝零钱通常在 1–3 个工作日到账，银行卡/信用卡通常在 3–7 个工作日到账。
