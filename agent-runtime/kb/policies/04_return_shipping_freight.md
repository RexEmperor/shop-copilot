# 退换货运费承担与运费险规则

## 退换货运费责任划分
- **商家原因导致的退换货**（包括商品质量问题、发错货、少件漏发、运输破损、商品与页面描述严重不符）：往返运费全部由商家承担。买家可先垫付普通快递运费（不含保价与顺丰特快溢价），商家收货核实后按实报销。
- **买家个人原因导致的退换货**（包括不喜欢、拍错款式/尺码、多拍等七天无理由退货）：退回运费由买家承担；若原订单为包邮商品，仅退回商品实付金额，不扣除原发货基础运费（偏远地区额外补差运费除外）。

## 运费险理赔说明
- 店铺对单笔实付满 **99 元** 的现货订单默认赠送基础退货运费险（特殊大件与虚拟商品除外）。
- 运费险仅在退货退款成功且系统核实物流签收后自动触发理赔，理赔金额按收发地首重标准定额赔付，单笔最高赔付 **12 元**，超出部分由买家自行承担。
- 同一笔订单仅理赔一次；拒签拦截件不触发运费险理赔。
