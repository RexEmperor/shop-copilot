# 商品价保服务规则

## 价保周期与适用条件
店铺在售现货商品默认提供 **7 天价保服务**（自订单支付成功之时起满 168 小时内）。
在价保周期内，若同一商品（同 SKU、同规格）在本店官方页面降价，导致降价后的到手价低于买家原下单实付单价，买家可申请退还差价。

## 差价计算与退款方式
- 差价 = 买家原订单实付单价 − 申请时该商品同规格同条件的实际到手价（需对比同等公开优惠券后的价格）。
- 价保审核通过后，差价将于 **24 小时内**原路退回买家的原支付渠道。

## 不参与价保的情形
以下特殊活动价格不计入价保比价范围：
1. 限量前 N 件秒杀、直播间专属口令闪降、新人首单专享补贴；
2. 店铺清仓临期特卖或已下架商品；
3. 使用平台随机红包、银行卡立减金或个人积分抵扣导致的个体实付差异；
4. 已发起整单退款或退货退款的订单。
