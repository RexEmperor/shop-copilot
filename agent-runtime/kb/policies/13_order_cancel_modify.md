# 订单取消与修改收货地址规则

## 订单取消规则
- **待支付状态（未付款）**：买家可随时自助取消订单，系统自动释放预占库存，不产生任何费用；
- **已支付、暂未发货状态**：若仓库尚未打单出库，买家可发起“仅退款”取消交易；如果该笔订单已存在进行中或已退款的售后工单，系统将禁止直接取消订单以防重复退款与库存错乱；
- **已发货或已完成状态**：订单进入履约环节，无法直接取消，请按退货退款流程或联系客服协助拦截快递。

## 修改收货地址与收件人信息
- **发货前修改**：下单后在仓库尚未打包出库前，可联系人工客服修改同省/同运费区域的收货地址、收件人姓名或联系电话；若跨偏远地区导致运费差额，建议取消原单后重新下单；
- **发货后改址**：包裹已由快递揽收后，商家无法在系统直接改址，仅可协助向快递网点申请“转寄/拦截”，转寄可能产生额外快递转寄费且不保证 100% 拦截成功。
