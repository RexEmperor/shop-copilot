# 支付方式与未支付超时取消规则

## 支持的支付方式
本店目前支持以下主流线上支付方式：
- 微信支付（零钱、零钱通、绑定储蓄卡与信用卡）；
- 支付宝支付（余额、余额宝、绑定银行卡）；
- 银联云闪付及主流国内借记卡快捷支付。
暂不支持货到付款（COD）及个人私下微信/支付宝转账，所有交易均须通过平台订单系统完成以保障资金安全。

## 未支付订单超时关闭机制
- 为防止恶意占库影响其他买家选购，订单创建后系统会锁定对应商品库存，买家需在 **30 分钟内**完成付款；
- 超过 **30 分钟**仍未完成支付的订单，系统将自动将其流转为“已取消”状态，并立即把扣减的库存返还至商品可售库存池；
- 已超时关闭的订单无法恢复支付，如需购买请重新提交新订单（以重新下单时的页面实时价格与库存为准）。
