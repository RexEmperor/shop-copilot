# 礼盒包装与代写贺卡服务规则

## 免费礼品包装与隐藏价格单
本店礼盒类商品（如每日坚果礼盒、香薰蜡烛礼盒）及数码送礼热门单品（无线蓝牙耳机 Pro、智能手表 S2）均支持送礼定制服务：
- **隐藏价格发货单**：下单备注“送礼不放价格单”或联系客服登记后，仓库出库时将移除含价格的明细小票，仅保留无价装箱清单；
- **防压加固包装**：礼盒外层默认加套加厚气泡膜与硬质外箱，尽量避免运输途中礼盒边角磕碰变形。

## 代写贺卡服务说明
- 每笔送礼订单可免费提供 **1 张精美祝福贺卡**，支持人工代写或印刷祝福语，字数建议控制在 **80 字以内**；
- 如需代写贺卡，请在付款后 **1 小时内**（仓库打单前）联系人工客服提交祝福文案；已打包出库的订单无法补放贺卡。
- 贺卡属于免费附赠服务，不单独收费，亦不支持指定特殊定制插画。
