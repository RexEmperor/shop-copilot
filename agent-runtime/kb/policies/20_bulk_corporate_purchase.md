# 企业团购与批量采购规则

## 团购起订门槛与阶梯折扣
本店欢迎企业行政采购、节日员工福利及商务伴手礼团购：
- **起订门槛**：单一商品一次性采购满 **20 件**，或整单采购总金额满 **5,000 元**，即可申请企业团购专属报价；
- **参考阶梯**：满 20 件享页面价 **95 折**，满 50 件享 **92 折**，满 100 件以上按实时库存与品项单独核价（部分特价促销商品不叠加团购折扣）。

## 对公付款、合同与专票流程
- 支持签订正规电子或纸质采购合同、支持**对公银行账户转账**结算；
- 企业团购可开具对应品类的**数电增值税专用发票**（如办公数码、劳保日用、节日食品礼盒），开票税率严格按国家财税规定执行；
- 因批量采购需提前锁定大额库存并核对开票资质，请直接回复“转人工”对接企业大客户经理，在线助手无法直接修改订单价格或锁大宗库存。
