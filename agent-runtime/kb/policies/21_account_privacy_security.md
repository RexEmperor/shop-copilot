# 账号安全、隐私保护与号码脱敏规则

## 订单与隐私数据隔离
- 店铺严格保护用户个人隐私，每位登录用户仅能查询和操作本人账号下的订单与售后记录，禁止跨账号代查或泄露他人收货信息；
- 在线客服系统采用**隐私号与脱敏展示**策略，物流面单默认隐藏收件人手机号中间 4 位数字，防止快递面单造成信息泄露；
- 聊天对话记录仅用于上下文理解与售后服务追溯，热缓存定期自动过期清理，不会向无关第三方出售或共享用户个人数据。

## 账号安全提醒
- 店铺官方客服**绝不会**以“订单异常、质量理赔、会员扣费取消”等名义向买家索要银行卡密码、短信验证码，或要求点击外部陌生链接下载屏幕共享软件；
- 所有退款与赔付均通过官方平台原路退回，如遇疑似诈骗电话或信息，请立刻通过官方渠道核实订单状态并报警。
