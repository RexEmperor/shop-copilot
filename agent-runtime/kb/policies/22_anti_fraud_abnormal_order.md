# 异常订单与风控拦截说明

## 高频访问与防刷单风控机制
为保障正常消费者的公平购买权益与平台系统稳定，接口层和交易层均设有风控保护：
- **接口频率限制**：短时间内超高频刷单、批量探测下单或恶意高频提交售后请求，可能触发系统的滑动窗口限流保护（返回请求过于频繁提示），请间隔 1 分钟后正常操作；
- **异常订单核验**：同一收货地址、手机号或设备在短时间内批量抢购限购商品、倒卖套利或存在明显虚假地址（如乱码地址、空号）的，风控系统有权暂停发货并联系买家核验身份。

## 风控拦截后的申诉处理
若正常消费者因公司集中下单、家庭多人同地址购买等合理原因误触发风控拦截：
- 请回复“转人工”并提供订单号与收货人信息，客服将在 **2 小时内**核实放行；
- 若订单因核验不通过被取消，已支付款项将 100% 原路退回，不扣除任何违约金。
