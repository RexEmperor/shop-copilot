## Phase 0 · 环境与基础设施

**1. 你的 Agent 项目为什么选双语言架构?边界怎么划分?**
素材:业务与数据在 Java(business-api,后续以 MCP Server 暴露工具),Agent 编排在 Python(agent-runtime);两侧只通过 MCP 协议 + HTTP(SSE)通信。
加分点:这是大厂真实架构形态;分工依据是"各自生态最强处"。

**2. 容器和虚拟机的本质区别?**
素材:学习记录 Docker 章——namespace(隔离视野)+ cgroup(限制用量),共享宿主机内核;别墅 vs 公寓隔间的类比。

**3. docker compose 管了哪些基础设施?healthcheck 为什么重要?**
素材:MySQL/Redis/PG(pgvector)/RocketMQ(namesrv+broker 双角色);healthcheck 让 `depends_on` 和编排系统知道"真的活着"而不只是"进程在"。

**4. 具名卷和绑定挂载的区别?你踩过具名卷什么坑?**
素材:RocketMQ 具名卷被 root 初始化,容器内 rocketmq 用户写不了 store → exit 255 无限重启;dev 期改为不挂数据卷。

**5. 一台机器上老服务和新容器抢端口,你怎么排查处理?**
素材:6379(本机 brew redis)与 3306(本机 Oracle MySQL)两个冲突;**非特权 lsof 的盲区**——两次"空闲"是假象,`sudo lsof` 才现形;决策:停用本机服务(数据不动)。

**6. 国内拉镜像报 denied,你的排查链路是什么?**
素材:加速器透传上游拒绝 → 核实上游(2026-09 MinIO 删库)→ 缓存镜像库存 → Bitnami 分身 → 切替代方案。教训:**加速器只是缓存,上游没有的东西变不出来**;"denied"≠网络墙。

**7. 如果你依赖的基础镜像某天被上游删除,怎么办?**
素材:MinIO 灭绝事件全程;供应链风险评估:缓存库存 → 分身 → 替代品 → 云服务;教训是选型时就要问"上游消失了怎么办"。

**8. 为什么密钥不能进代码库?.env 惯例怎么落地?**
素材:仓库 .gitignore 配 .env + 提交 .env.example 模板;验证手段:`git status` 里永远看不到 .env;12-factor 的 config 原则。

**9. 多个 JDK 共存时你怎么管理?**
素材:全局默认 JDK8 不动(保护老项目),项目级 env.sh(`java_home -v 17` + PATH 前插);IDEA 用自己的 Project SDK。

## Phase 1 · LLM 应用工程化

**1. LLM 天生无状态,多轮"记忆"怎么实现的?为什么双存储而不是单存一端?**
素材:MySQL 唯一事实源(审计、防丢)+ Redis 热缓存(TTL 7 天、活跃续期);cache-aside:读先缓存、未命中回源 MySQL 并回填;实测"删缓存后提问记忆完好"(prompt_tokens 128, llen=4)。

**2. cache-aside 回源的正确时序是什么?你踩过什么坑?**
素材:回源事故——写缓存(user 消息 rpush)先于读历史,新消息占住空缓存,"非空假象"绕过回源;修复为先 get_history 预热再 append;数字证据 69 vs 128。

**3. 上下文长度为什么会失控?你怎么控制?代价是什么?**
素材:prompt_tokens 33→69→97→123;HISTORY_MAX_MESSAGES 截断取最近 N 条;代价是丢早期信息 → 摘要组合策略(backlog)。

**4. function calling 的完整链路是什么?模型真的"执行"了工具吗?**
素材:模型只输出 JSON 意图(tool_calls),本地代码 execute 后把结果以 role=tool 喂回,再进入下一轮思考;mock 测试断言第二轮 messages 里含 role=tool。

**5. 工具 schema 怎么生成的?和 LangChain @tool 的原理关系?**
素材:mini 注册器 = 签名反射(inspect)+ OpenAI schema 协议转换;docstring 首行即描述——框架没有魔法。

**6. 为什么 session_id 由代码注入而不让模型填?工具参数做了哪些校验?**
素材:模型上下文里没有 session_id,让它填=逼它编造;三层兜底:未知工具/多余参数丢弃/异常转错误文本;上下文注入参数不进 schema。

**7. 工具执行抛异常,系统会怎样?MAX_ROUNDS 防什么?**
素材:异常转为错误文本交回模型自行决定下一步(对话不崩);MAX_ROUNDS=4 防模型无限要工具烧钱烧时间;测试 boom 工具验证。

**8. SSE 打字机的协议本质?工具过程为什么只能发状态事件?**
素材:`data: {...}\n\n` 长连接 + FastAPI StreamingResponse;事件协议 tool_status/tool_result/delta/final;中间过程不是回答——不能流成文本,否则用户看到内心独白和 JSON 碎片。

**9. Langfuse 怎么接入的?成本核算的前提是什么?**
素材:@observe 三处装饰(生成层级树 agent-chat→deepseek-chat→tool-execute)+ propagate_attributes 传 session(SDK 5.x 新 API);成本只算 generation 类型——需 as_type="generation" + update_current_generation 挂 model/usage_details;span 永远是 "—"。

**10. pytest-asyncio 的 Event loop is closed 怎么回事?**
素材:每测试一个新循环 vs 模块级 Redis 连接池/DB 引擎单例;`asyncio_default_test_loop_scope=session` 全程一个循环,模拟生产 uvicorn 语义。

**11. 模型覆盖了工具返回的权威数据怎么办?**
素材:实测工具返回 3 条消息,模型答 4 条(自己推理补的);查库存/余额场景这是事故 → 护栏(强制引用工具输出、后校验)进 Phase 5。

**12. Agent 怎么测试?不真调 LLM 能测吗?**
素材:mock fake_chat 剧本驱动(第一轮要工具、第二轮作答),断言喂回机制与历史落库;8 例回归 0.7s 跑完,0 API 成本;集成测试则打真容器(MySQL 回源)。

**13. (开放)讲一个你阶段里最难的 bug。**
候选素材(任选,全部有 PLAN 日志佐证):缓存回源顺序 bug + 脏数据污染 / 非特权 lsof 盲区 / MinIO 灭绝事件 / SDK 版本漂移 introspection 三步法。
